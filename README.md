China Town API is a production-oriented backend built with NestJS, PostgreSQL, and Prisma for a smart restaurant ordering and management platform.

The system provides secure authentication and role-based access control for customers, staff, and administrators. It handles restaurant menus, cart and order processing, staff order workflows, inventory management, wallet-based payments, reviews, notifications, and real-time order status updates.

The platform also incorporates AI-based features, including fake review detection and intelligent restaurant-related functionality, making the project more than a traditional CRUD-based restaurant application.
